CloudWatch Log Extractor

Chrome Extension to extract and parse CloudWatch log entries. Copies the log stream, then extracts fields and generates a cURL command.

@if (showExtensionHelp) {

How to install & use the extension

1
Download & unzip

Click "Download Extension (.zip)" above and unzip the file.

2
Load in Chrome

Open chrome://extensions, enable "Developer mode", then click "Load unpacked" and select the unzipped folder.

3
Open CloudWatch Logs

Go to AWS CloudWatch → Logs → Log Insights and run your query.

4
Open a log stream

Click on a log entry to expand it, then click on the @logStream link to open the full log stream.

5
Copy the log entry

Expand the log message you're interested in. Select and copy the full log text (Ctrl+C / Cmd+C).

6
Extract with the extension

Click the CloudWatch Log Extractor extension icon in Chrome toolbar, then click "Extract from Clipboard".

7
Get the cURL command

The extension will parse the log and show you extracted fields (API name, URL, status, etc.) and a ready-to-use cURL command you can copy.

The extension reads from your clipboard — make sure you've copied the log entry before clicking "Extract from Clipboard".
